# Lakehouse Week-Wise Learning Structure

This directory contains a week-by-week learning plan for a local lakehouse course.

## Structure

- `week-1/` — Ingestion, storage, and local environment setup
- `week-2/` — Parquet, Spark, tables, and metadata
- `week-3/` — Streaming, partitioning, and operational resilience
- `week-4/` — Orchestration, querying, and governance
- `week-5/` — Data quality, catalog discovery, and advanced governance
